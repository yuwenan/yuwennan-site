## 01 / 收藏之后，还能不能找到并用上

提示词越积越多时，单纯保存文本很难支撑下一次使用。用户需要记住它适合什么场景、依赖哪些素材，以及最终会产生什么效果。

Prompt Hub 围绕“查找 → 判断 → 编辑 → 复用”组织体验，把文本、标签与预览放在一起。

## 02 / 我的工作

设计提示词的分类、标签和词汇组织方式，梳理卡片、搜索筛选、详情编辑和预览之间的关系，并借助 AI 工具完成个人工作台的实现。

## 03 / 在使用之前看见效果和适用条件

详情页把效果图、机制说明、适用场景、实现说明和完整提示词放在一起。这样，选择提示词时就能先判断是否适合当前任务，再决定复制或调整。

## 04 / 分类负责归档，标签支持交叉查找

同一条提示词可能同时对应多个场景。用分类建立基本目录，再通过标签补充主题、表现方式等属性，可以从不同角度重新找到它。

<Figure src={tags} alt="Prompt Hub 标签管理界面" caption="标签管理：为提示词建立跨分类的查找维度。" />

## 阶段交付与产品思考

项目形成分类、标签、搜索筛选、编辑与预览功能；数据和图片由后端管理，并通过 Git 记录变更。

这个案例关注的是个人知识和工作素材的复用体验。把“保存下来”推进到“下次真的用得上”，需要让信息组织方式贴近具体任务。
